# 쉬운 한국어: AI 웹 시제품

## 시작하기
1. Python 3.10 이상 설치
2. VS Code에서 이 폴더 열기
3. 터미널에서 아래 명령 실행

```bash
python -m pip install -r requirements.txt
```

4. OpenAI API 키 발급: https://platform.openai.com/api-keys
   - ChatGPT 구독과 API 비용은 별개입니다.
   - 프로젝트 폴더에 `.streamlit` 폴더를 만들고 `secrets.toml` 파일 생성
   - 아래 내용을 넣되 YOUR_KEY를 실제 키로 변경:
```toml
OPENAI_API_KEY = "YOUR_KEY"
```
5. 터미널에서 실행
```bash
python -m streamlit run app.py
```
6. 브라우저에서 http://localhost:8501 접속

## 현재 제공
- AI 쉬운 단어 검색 및 예문
- 선택한 단어의 AI 일러스트 생성 (별도 API 사용료 발생)
- 텍스트 / PDF / DOCX / JPG / PNG 업로드
- 카메라 촬영 및 AI 글자 읽기
- 원문 / 쉬운 문장 나란히 확인 (초기 버전은 위아래)
- 기본 문서 예시 3개
- 쉬운 문장 텍스트 다운로드

## 한계와 주의
- PDF는 첫 3쪽만, 텍스트는 최대 15,000자 처리합니다.
- 문서 안의 해당 위치에 쉬운 표현을 겹쳐 보여주는 기능은 아직 없습니다.
- 그림은 실시간 생성되므로 응답시간과 비용이 증가합니다.
- 결과와 OCR은 부정확할 수 있습니다. 중요한 서류는 원문과 비교하세요.
- 주민등록번호, 의료기록 등 개인정보가 있는 문서는 테스트에 사용하지 마세요.
- API 키는 공개 저장소에 올리지 마세요.

## 사용자 쉬운 한국어 변환 규칙 (v2)
- `app.py`의 `SYSTEM` 변수에 사용자가 제공한 어휘, 문장, 어조, 숫자와 목록 규칙을 반영했습니다.
- 단어 검색, 문서·사진 변환, 기본 문서 변환에 공통 적용됩니다.
- 의미 보존을 우선하므로 중요한 수치·부정·법적 조건은 그대로 유지할 수 있습니다.
- 아직 원문 위에 쉬운 글을 겹쳐 표시하는 기능은 없습니다.
